# 白话译文

底本为 `../volumes/` 同号 TXT，不是 `../raw/` 的完整译文，也不是 110 卷重编全书的同号卷。

当前初稿：`001.txt`–`220.txt`，共 220 卷、22,889 个编号段落，编号和纪年标题与底本一致。AI 辅助翻译，尚待人工逐段语义校对；结构核验不代表译文定稿。已记录的底本疑点见 [校对疑点.md](校对疑点.md)。

## 翻译约定

- 每卷使用 UTF-8、三位卷号文件名；逐段完整翻译，不合并、删除或重排编号。
- 保留 `○`／`◎` 纪年标题和人名、地名、官职等专名；把叙事、对话译成现代汉语，不用机械字词替换。
- 尊重底本文意，不凭其他史料悄悄改写疑误；发现问题时另行报告原文与段落编号。
- 完稿后与底本逐段核对，再运行 `python3 scripts/build_catalog.py`。脚本检查编号和纪年标题是否一致，生成已译清单、静态页、切换入口和站点地图；结构检查不代表译文已通过语义校对。
- 新增译文须连同 `assets/vernacular.json`、相关阅读页和 `sitemap.xml` 提交。若撤下既有译文，应检查并删除其旧生成页面；脚本不会主动删除已有文件。

## 验收

检查静态页和增强阅读器的文言／白话往返、未译提示、前后卷、全文查找、目录、深链接、分享链接及各版本独立进度。关闭 JavaScript 后，已译卷仍可通过原生链接阅读全文和下载 TXT。
